 Simple Interest Calculator

Description
This project is a simple interest calculator that calculates the interest earned using the formula:

Simple Interest = (Principal × Rate × Time) / 100

Features
 Calculates simple interest
 Easy to use
 Simple and clear output

 Formula
SI = (P × R × T) / 100

 Example

Principal: 10000
Rate: 5%
Time: 2 years

Simple Interest = 1000
